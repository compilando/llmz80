## Available Z88DK Functions

### Screen Functions (from arch/zx.h)
- `zx_border(color)` - Set border color (INK_BLACK, INK_BLUE, INK_RED, INK_MAGENTA, INK_GREEN, INK_CYAN, INK_YELLOW, INK_WHITE)
- `zx_cls(attr)` - Clear screen with attribute (e.g., PAPER_BLACK | INK_WHITE)
- `zx_plot(x, y, color)` - Plot a pixel at (x,y)
- `zx_point(x, y)` - Test if pixel at (x,y) is set

### Standard I/O (from stdio.h)
- `printf(format, ...)` - Print formatted text
- `sprintf(buffer, format, ...)` - Format string to buffer
- `putchar(c)` - Output single character
- `getchar()` - Get single character

### Keyboard Input (from input.h)
- `in_inkey()` - Read keyboard, returns scancode or 0
- `in_key_pressed(scancode)` - Check if specific key is pressed
- `in_wait_key()` - Wait for key press
- `in_wait_nokey()` - Wait for key release

### Sound (from sound.h)
- `bit_beep(duration_ms, frequency_hz)` - Simple beep
- `bit_fx(effect_number)` - Play sound effect
- `bit_synth(effect_number, duration)` - Synthesized sound

## Important Constants

### Colors (for zx_border)
- INK_BLACK, INK_BLUE, INK_RED, INK_MAGENTA
- INK_GREEN, INK_CYAN, INK_YELLOW, INK_WHITE

### Attributes (for zx_cls)

## Memory Constraints

- ZX Spectrum 48K has 32KB RAM available
- Avoid large arrays (>8KB)
- Avoid dynamic memory allocation (malloc/free)
- Use static arrays instead

## Common Patterns

### Display Text
```c
#include <arch/zx.h>
#include <stdio.h>

void main(void) {
    zx_cls(PAPER_BLACK | INK_WHITE);
    printf("Hello, World!\n");
    while (1);
}
```

### Change Border
```c
#include <arch/zx.h>

void main(void) {
    zx_border(INK_RED);
    while (1);
}
```

### Keyboard Input
```c
#include <arch/zx.h>
#include <input.h>
#include <stdio.h>

void main(void) {
    zx_cls(PAPER_BLACK | INK_WHITE);
    printf("Press any key...\n");
    in_wait_key();
    printf("Key pressed!\n");
    while (1);
}
```
