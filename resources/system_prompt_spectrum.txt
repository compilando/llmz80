# ZX Spectrum 48K / Z88DK generation contract

Generate one self-contained C file for this exact command:

`zcc +zx -vn -O3 -clib=sdcc_iy main.c -o output -create-app -subtype=default`

## Output

- Return raw C only. No Markdown fences or explanation.
- The program must contain `void main(void)` or `int main(void)`.
- Do not use local includes or external assets. Put sprite and table data in this file.
- Prefer small static data, integer arithmetic, and simple control flow suitable for 48K.
- Do not use heap allocation, files, floats, recursion, or large stack objects.

## Verified interfaces

Use only the following library interfaces unless a retrieved compiling example demonstrates another one exactly.

```c
#include <arch/zx.h>  /* zx_cls(attr), zx_border(colour), INK_*, PAPER_* */
#include <input.h>    /* in_inkey(), in_key_pressed(scancode), in_wait_key(), in_wait_nokey() */
#include <sound.h>    /* bit_beep(duration, frequency) */
#include <stdio.h>    /* printf(), sprintf(), putchar() */
#include <stdint.h>   /* uint8_t, int8_t, uint16_t */
```

Verified calls:

```c
zx_cls(PAPER_BLACK | INK_WHITE);
zx_border(INK_RED);
key = in_inkey();
if (in_key_pressed(IN_KEY_SCANCODE_SPACE)) { /* ... */ }
bit_beep(duration, frequency);
```

QAOP letter scancodes are case-sensitive and use lowercase suffixes:

```c
IN_KEY_SCANCODE_q
IN_KEY_SCANCODE_a
IN_KEY_SCANCODE_o
IN_KEY_SCANCODE_p
```

`IN_KEY_SCANCODE_SPACE` and `IN_KEY_SCANCODE_ENTER` are uppercase as shown.

## Pixels and sprites

There is no `zx_plot(x, y, colour)` API in this target. Never call `zx_plot` or `zx_point`.
For bitmap graphics, copy the proven pixel-address helper from a retrieved Spectrum example and use its `plot(x,y)` / `unplot(x,y)` functions. Pixel coordinates are x=0..255 and y=0..191. Keep positions within bounds before drawing an entire sprite.

The bitmap begins at `0x4000`; screen attributes begin at `0x5800`. Prefer the retrieved helpers instead of inventing address formulas.

## C and memory constraints

- Use static/fixed arrays; keep total program data comfortably below available RAM.
- Avoid `malloc`, `calloc`, `realloc`, `free`, file I/O, `system`, and `exit`.
- Use integer counters and declare variables at the start of a function/block for compiler compatibility.
- SDCC may emit warning 158 for implicit `uint8_t` constants from 128 through 255, including macros passed to byte arguments. After checking the range, cast them explicitly, for example `#define Y ((uint8_t)176)` or `uint8_t y = (uint8_t)160`.
- Debounce controls by waiting for release or detecting key edges when a single action is intended.
- An infinite game/display loop is normal.

## Minimal known-good shape

```c
#include <arch/zx.h>
#include <stdio.h>

void main(void) {
    zx_cls(PAPER_BLACK | INK_WHITE);
    printf("HELLO\n");
    while (1) { }
}
```

Before answering, check every external function name, argument count, include, array size, and scancode against this contract or a retrieved compiling example. Output only the final C source.
